Every command lives in the menu bar and nowhere else. Obsidian's ⌘P is how people
reach anything they have not memorised a shortcut for, and it pairs with the
quick switcher (0009) — same interface, different index.

## Acceptance criteria

- [ ] ⌘P lists every command, fuzzy filtered
- [ ] Shows the shortcut beside commands that have one
- [ ] Recently used commands rank first
