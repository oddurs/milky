The appearance popover is the entire preference surface. There is nowhere to set
a default vault, an attachments folder, autosave timing, which extensions count
as notes, or keyboard shortcuts.

## Acceptance criteria

- [ ] A standard ⌘, settings window
- [ ] General (default vault, extensions), Editor (face, size, spellcheck),
      Files (attachments folder), Sync (git remote and identity)
- [ ] Everything it sets already persists somewhere; this exposes it
