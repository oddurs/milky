Moving between notes means reaching for the note list. A modal switcher on Command-O that filters titles as you type is the single largest daily-use gap.

## Acceptance criteria

- [ ] Command-O opens a centred palette over the window
- [ ] Fuzzy match on titles, ranked, arrow keys to move, Return to open
- [ ] Escape restores focus to the editor and the caret position
